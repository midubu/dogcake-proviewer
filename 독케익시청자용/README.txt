dogcake proviewer
=================

치지직 방송 감시 및 방송 타임라인 기록 프로그램

현재 버전: v1.8.94

dogcake proviewer는 치지직 방송 상태를 감시하면서 방송 중 원하는 순간을 타임라인으로 기록하고, 이후 치지직 VOD가 업로드되면 해당 타임라인을 VOD의 실제 재생 위치와 자동으로 연결하는 AutoHotkey v2 기반 프로그램입니다.


1. 주요 기능
============

[치지직 방송 감시]

- 방송 시작 감지
- 방송 종료 감지
- 방송 시작시간 기록
- 방송 시작 시 치지직 방송 페이지 자동 실행
- 방송 종료 후 컴퓨터 종료 예약
- 방송 재개 감지
- 치지직 API 오류 발생 시 자동 재시도
  - 5초 후 재시도하고, 실패가 이어지면 최대 60초 간격까지 단계적으로 대기
  - 연결이 복구되면 기존 30초 감시 주기로 자동 복귀
- 방송 카테고리 변경 이력 및 직전 카테고리 이용 시간 기록
  - 기록 파일: data\category_history.csv
  - 감시 주기 30초 기준으로 변경 시각은 실제 변경보다 최대 약 30초 늦을 수 있음

방송이 잠시 종료되었다가 다시 시작되는 경우에도 방송 세션을 구분합니다.

기본적으로 방송 종료 후 2시간 이내에 다시 시작하면 같은 방송으로 취급하며,
2시간을 초과하면 새로운 방송으로 처리합니다.


[컴퓨터 자동 종료]

방송 종료 후 일정 시간이 지나면 컴퓨터 종료를 예약할 수 있습니다.

기본 설정:
- 종료 예약: 활성화
- 종료 대기시간: 5분

다음 상황에서는 종료 예약이 취소됩니다.

- 야간 보호 시간
- 보호 앱이 실행 중인 경우
- 사용자가 직접 종료 예약을 취소한 경우


[야간 보호]

설정된 시간 동안 컴퓨터 자동 종료 기능을 보호합니다.

기본값:
- 시작: 22:30
- 종료: 04:00

야간 보호 시간에 들어가면 기존 종료 예약이 취소됩니다.

시간은 HH:MM 형식으로 설정할 수 있습니다.


[보호 앱]

특정 프로그램이 실행 중일 경우 컴퓨터가 자동으로 종료되지 않도록 설정할 수 있습니다.

예를 들어 작업 중인 프로그램이나 게임 등을 보호 앱으로 등록할 수 있습니다.

보호 앱 설정은 data\protected_apps.ini에 저장됩니다.


2. 타임라인 메모
================

방송을 시청하면서 원하는 순간에 타임라인을 기록할 수 있습니다.

타임라인에는 다음 정보가 저장됩니다.

- 방송시작
- 방송시간
- 메모
- 기록시각
- VOD링크
- VOD제목

예:

방송시작: 2026-09-30 18:00:00
방송시간: 01:26:11
메모: 재미있는 장면
기록시각: 2026-09-30 19:26:15
VOD링크: 연결된 치지직 VOD


타임라인 데이터는 다음 파일에 저장됩니다.

data\timeline.csv

VOD가 연결되면 VOD 제목도 타임라인 뷰어에 표시됩니다.
타임라인 뷰어의 'VOD 재연결' 버튼은 미연결 VOD를 재연결한 뒤, 이미 연결된 VOD를 포함해 제목이 비어 있는 행의 영상 제목도 함께 보완합니다.
깨진 문자로 저장된 기존 VOD 제목도 재연결 버튼을 누르면 다시 조회해 정상 제목으로 교체합니다.
타임라인 목록에 마우스를 올리면 해당 영상 시간에 방송 중이던 게임/카테고리와 VOD 제목을 볼 수 있습니다. 카테고리 기록이 없는 과거 방송은 표시되지 않습니다.


3. 방송 경과시간
================

타임라인의 '방송시간'은 실제 시계 시간이 아니라 방송 시작 후 경과시간입니다.

예:

방송 시작
18:00:00

타임라인 기록
19:26:11

방송시간
01:26:11

방송이 자정을 넘어가더라도 방송 경과시간은 계속 이어집니다.


4. 장시간 방송 및 VOD 분할
===========================

방송을 중간에 끄지 않아도 CHZZK의 영상 길이 제한 때문에 하나의 긴 방송이 여러 개의 VOD로 나뉠 수 있습니다.

예:

방송
 |
 +-- VOD 1
 |    00:00:00 ~ 02:00:00
 |
 +-- VOD 2
      02:00:00 ~ 04:00:00

방송 경과시간이 18:11:00이고 VOD 1의 길이가 17시간이라면 VOD 2의 영상 위치는 01:11:00으로 계산합니다.

즉, VOD가 여러 개로 분할되어도 전체 방송의 경과시간을 기준으로 적절한 VOD와 재생 위치를 찾습니다.
VOD별 시작 시각이 방송 시작 시각과 다르게 기록된 경우에도, 앞 VOD 길이와 다음 VOD 시작 시각이 이어지는지 확인해 분할 순서를 찾습니다.


5. VOD 자동 연결
================

타임라인을 기록했을 당시 VOD가 아직 업로드되지 않았다면 VOD 링크가 비어 있는 상태로 저장됩니다.

이후 프로그램이 VOD를 다시 확인하여 자동으로 연결합니다.

동작 방식:

타임라인 기록
    |
    +-- VOD 존재
    |      |
    |      +-- 즉시 연결
    |
    +-- VOD 없음
           |
           +-- 10분 후 재확인
           |
           +-- VOD 업로드 확인
           |
           +-- 자동 연결

타임라인 저장 직후에도 한 번 즉시 확인합니다.


6. 이미 연결된 VOD는 재검사하지 않음
====================================

VOD 링크가 이미 연결된 타임라인은 VOD 재연결 대상에서 제외됩니다.

예:

[연결됨] -> 검사하지 않음
[연결됨] -> 검사하지 않음
[미연결] -> VOD 검색
[미연결] -> VOD 검색
[연결됨] -> 검사하지 않음

수동 'VOD 재연결' 기능을 사용하더라도 이미 연결된 타임라인은 다시 검색하지 않습니다.

이를 통해 불필요한 치지직 API 요청과 검색 시간을 줄입니다.


7. VOD 검색 범위
================

현재 설정:

- 페이지 크기: 30개
- 최대 페이지: 20페이지
- 최대 약 600개 VOD 검색

30 x 20 = 600

방송 시작시간과 VOD의 방송 시작시간을 비교하여 해당 방송에 속하는 VOD를 찾습니다.

방송 시작시간 비교에는 일정한 허용 오차가 적용되며 기본값은 180초입니다.


8. 타임라인 뷰어
================

타임라인 뷰어에서는 저장된 기록을 달력 형태로 확인할 수 있습니다.

기능:

- 월별 달력
- 타임라인 창을 열면 오늘 날짜를 기본 선택
- 타임라인이 존재하는 날짜 확인
- 특정 날짜의 타임라인 목록 확인
- 타임라인 수정
- 타임라인 삭제
- VOD 재연결
- 선택한 VOD의 타임라인 메모와 카테고리 변경 내역으로 챕터 생성 및 클립보드 복사
- VOD 제목 앞의 ◀ 화살표와 제목 뒤의 연결 상태 원을 표시(연결됨은 초록색, 미연결은 빨간색)
- 타임라인 더블클릭으로 해당 VOD 위치 열기
- 수동 타임라인 추가
- 날짜·영상 시간·메모·VOD 제목을 대상으로 전체 타임라인 검색

검색어를 입력하면 선택 날짜에 관계없이 전체 기록에서 일치 항목을 찾습니다. 여러 단어를 입력하면 모든 단어가 포함된 항목만 표시합니다. 검색어를 지우면 선택한 날짜의 목록으로 돌아갑니다.

날짜 기준:

타임라인은 기록한 날짜가 아니라 방송 시작 날짜를 기준으로 분류됩니다.

예:

방송 시작
2026-09-30 23:00

방송 종료
2026-10-01 05:00

이 방송의 타임라인은 2026-09-30 날짜에 속합니다.

자정을 넘어갔다고 해서 새로운 날짜의 방송으로 분리하지 않습니다.


9. 수동 타임라인
================

방송 중이 아니거나 기존 방송의 기록을 직접 추가해야 하는 경우 수동 타임라인 기능을 사용할 수 있습니다.

입력 가능한 정보:

- 치지직 VOD 링크
- 영상 시간 (VOD 안에서 이동할 위치)
- 메모

VOD 링크를 입력하면 VOD 정보를 확인하여 방송 날짜를 지정할 수 있습니다.

수동으로 입력한 타임라인에도 VOD 재생 위치가 연결됩니다.


10. 타임라인 수정
=================

저장된 타임라인을 선택하고 수정할 수 있습니다.

수정 시에는 VOD 링크가 필요합니다.

수정 화면의 '영상 시간'은 전체 방송 경과시간이 아니라, 연결된 VOD 안에서 열 재생 위치입니다.

타임라인을 수정할 때 기존 CSV를 먼저 백업한 후 변경 내용을 저장합니다.


11. 타임라인 삭제
=================

선택한 타임라인을 삭제할 수 있습니다.

삭제하기 전에 확인 절차가 있으며, 실제 삭제 전에 CSV 백업이 생성됩니다.


12. CSV 백업
===========

타임라인 데이터는 자동으로 백업됩니다.

백업 폴더:

data\timeline_backup\

백업 파일 예:

timeline_20260930_193015_before_add.csv


백업이 생성되는 경우:

- 타임라인 추가
- 타임라인 수정
- 타임라인 삭제
- VOD 자동 연결로 CSV 내용이 실제 변경된 경우

자동 VOD 연결은 너무 많은 백업 파일이 만들어지는 것을 방지하기 위해
60초 이내 중복 백업을 제한합니다.

백업 파일은 최대 100개까지 유지됩니다.

100개를 초과하면 가장 오래된 백업부터 자동으로 삭제됩니다.


13. 단축키
==========

Ctrl + Alt + C
    컴퓨터 종료 예약 취소

Ctrl + Alt + P
    방송 감시 종료

Ctrl + Alt + M
    모니터 끄기

Ctrl + Alt + L
    설정 열기

Ctrl + Alt + K
    타임라인 메모

Ctrl + Alt + O
    타임라인 뷰어

단축키는 설정 화면 오른쪽 위의 '단축키 설정' 버튼에서 변경할 수 있습니다.

변경 방법:

1. 바꿀 기능의 키 입력 칸을 클릭합니다.
2. 원하는 키 조합을 누릅니다. 입력 중에는 키가 단축키 설정 창에서 처리되며 다른 앱으로 전달되지 않습니다.
3. Windows 키 조합을 쓰려면 해당 항목의 Win 체크박스를 켭니다.
4. 저장을 누르면 새 단축키가 즉시 적용됩니다.

Esc를 누르면 해당 입력을 취소합니다. 같은 조합을 여러 기능에 지정할 수 없으며,
중복되거나 등록할 수 없는 조합은 오류 안내가 표시됩니다.

단축키 설정은 data\settings.ini의 [Hotkeys] 항목에 저장됩니다.


14. 설정
========

Ctrl + Alt + L을 누르면 설정 화면을 열 수 있습니다.

설정 가능한 주요 항목:

- 자동 종료 사용 여부
- 종료 대기시간
- 야간 보호 시작시간
- 야간 보호 종료시간
- 보호 앱
- YouTube 관련 기능
- 기타 프로그램 설정

설정은 data\settings.ini에 저장됩니다.


15. YouTube 연동
================

YouTube 자동 실행 기능을 사용할 수 있습니다.

특정 채팅 트리거가 감지되면 YouTube 관련 동작을 실행하도록 설정할 수 있으며,
반복 실행을 방지하기 위해 쿨다운 시간을 설정할 수 있습니다.

기본 트리거:

똥! ㅋㅋ

기본 쿨다운:

60분

YouTube 기능은 설정에서 활성화할 수 있습니다.


16. 채팅 감시
=============

프로그램에는 치지직 채팅 트리거를 처리하기 위한 별도의 PowerShell 보조 스크립트가 사용됩니다.

관련 파일:

chzzk_chat.ps1
data\chzzk_chat_queue.txt
data\chzzk_chat_trigger.txt

릴리스에 chzzk_chat.ps1을 첨부하면 기존 파일을 교체합니다. 첨부하지 않은 일반 업데이트는 기존 파일을 유지하고, 설치 폴더에 helper가 없을 때만 같은 버전 태그의 저장소 루트에서 새로 받습니다.

채팅 감시 기능은 프로그램 실행 중 사용 설정에 따라 동작합니다.


17. 프로그램 파일
=================

프로그램 폴더에는 다음과 같은 파일이 생성될 수 있습니다.

dogcake_proviewer_v1.8.79.ahk
data\settings.ini
data\protected_apps.ini
data\timeline.csv
data\timeline_backup\
chzzk_chat.ps1
data\chzzk_chat_queue.txt
data\chzzk_chat_trigger.txt
dogicon.ico

모든 파일이 항상 존재하는 것은 아니며 기능 사용 여부에 따라 생성됩니다.


18. 실행 환경
=============

필수:

- Windows
- AutoHotkey v2.0

본 프로그램은 AutoHotkey v2 문법으로 작성되었습니다.

AutoHotkey v1에서는 실행할 수 없습니다.


19. 데이터 저장 구조
====================

전체적인 데이터 흐름:

치지직 방송
    |
    +-- 방송 상태 감시
    |
    +-- 방송 시작시간 확인
    |
    +-- 방송 경과시간 계산
    |
    +-- 타임라인 기록
             |
             v
        data\timeline.csv
             |
             v
        VOD 업로드 확인
             |
             v
        VOD 자동 매칭
             |
             v
        VOD 재생 위치 링크 생성


20. 방송 세션 처리
==================

방송이 종료된 후 다시 시작하는 경우 다음 기준으로 방송을 구분합니다.

[2시간 이내 재개]

방송 시작
    |
방송 종료
    |
2시간 이내 재개
    |
기존 방송으로 처리

기존 방송 시작시간을 유지합니다.


[2시간 초과 후 재개]

방송 시작
    |
방송 종료
    |
2시간 초과
    |
방송 재개
    |
새로운 방송으로 처리

새로운 방송 시작시간을 사용합니다.


21. 주의사항
============

[치지직 API 상태]

방송 상태와 VOD 정보는 치지직 API를 통해 확인합니다.

다음과 같은 경우 정상적으로 정보를 가져오지 못할 수 있습니다.

- 치지직 API 오류
- 네트워크 오류
- 서버 응답 지연
- API 응답 형식 변경
- VOD가 아직 업로드되지 않은 경우

VOD가 아직 존재하지 않는 경우 프로그램은 일정 시간 후 다시 확인합니다.


[data\timeline.csv 관리]

data\timeline.csv에는 타임라인 기록이 저장됩니다.

직접 삭제하거나 수정하기 전에 백업을 권장합니다.

자동 백업 파일은 data\timeline_backup\에 저장됩니다.


[프로그램 폴더 이동]

설정 및 타임라인 데이터는 기본적으로 프로그램이 실행되는 폴더를 기준으로 저장됩니다.

프로그램을 이동하면 새로운 위치에 별도의 설정 및 데이터 파일이 생성될 수 있습니다.

기존 데이터를 계속 사용하려면 다음 파일과 폴더도 함께 이동해야 합니다.

data\settings.ini
data\protected_apps.ini
data\timeline.csv
data\timeline_backup\
