DOGCAKE PROVIEWER
=================
치지직 방송 감시 + 타임라인 관리 프로그램
현재 버전: v1.8.34

1. 프로그램 소개
----------------
DOGCAKE PROVIEWER는 특정 치지직 채널의 방송 상태를 주기적으로 확인하면서,
방송 종료에 따른 PC 자동 종료, 야간 보호, 종료 보호 프로그램,
채팅 문구 감지에 따른 YouTube 실행, 방송 타임라인 기록 및 VOD 연결을
하나의 프로그램에서 관리하기 위한 AutoHotkey v2 프로그램입니다.

프로그램은 치지직 Live Status API와 VOD API를 이용하며,
타임라인 데이터는 프로그램 폴더의 timeline.csv에 저장됩니다.


2. 주요 기능
------------

[방송 감시]
- 치지직 방송 상태를 주기적으로 확인합니다.
- 기본 확인 간격은 30초입니다.
- 방송 시작(OFF → ON)이 감지되면 기본 브라우저로 치지직 방송 페이지를 엽니다.
- 방송 종료(ON → OFF)가 감지되면 설정에 따라 PC 종료 예약을 진행합니다.

[방송 종료 후 PC 자동 종료]
- 방송 종료 후 지정한 시간이 지나면 Windows 종료를 예약합니다.
- 기본값은 방송 종료 후 5분입니다.
- 기능을 끌 수 있습니다.
- 종료 예약이 걸린 상태에서 방송이 다시 시작되면 종료 예약을 취소합니다.

[야간 종료 보호]
- 지정된 시간에는 방송 종료에 따른 PC 자동 종료를 막습니다.
- 기본 보호 시간: 22:30 ~ 04:00
- 야간 보호 시간에 들어가면 기존 종료 예약도 취소합니다.
- 시작 시간이 종료 시간보다 늦은 경우(예: 22:30 ~ 04:00) 자정을 넘기는 시간대로 처리합니다.

[종료 보호 프로그램]
- 사용자가 지정한 프로그램이 실행 중이면 방송 종료 후 PC 자동 종료를 막습니다.
- 설정 화면에서 보호할 프로그램을 선택할 수 있습니다.
- 보호 프로그램은 별도의 protected_apps.ini에 저장됩니다.

[YouTube 자동 실행]
- 치지직 채팅에서 지정한 문구가 정확히 일치하면 YouTube 실행 기능을 사용할 수 있습니다.
- 기본 감지 문구: 똥! ㅋㅋ
- 기본 쿨타임: 60분
- 기능은 기본적으로 꺼져 있습니다.
- 채팅 감지 기능을 사용하려면 프로그램 폴더의 chzzk_chat.ps1이 사용됩니다.


3. 단축키
---------

Ctrl + Alt + C
- 현재 예약된 컴퓨터 종료를 취소합니다.

Ctrl + Alt + P
- 방송 감시 프로그램을 종료합니다.

Ctrl + Alt + M
- Windows 모니터를 끕니다.

Ctrl + Alt + L
- 통합 설정 창을 엽니다.

Ctrl + Alt + K
- 타임라인 메모 입력 창을 엽니다.

Ctrl + Alt + O
- 타임라인 뷰어를 엽니다.


4. 설정
-------

Ctrl + Alt + L로 통합 설정 창을 열 수 있습니다.

설정 항목:

- 방송 종료 후 컴퓨터 자동 종료 ON/OFF
- 종료 대기 시간(분)
- 야간 종료 보호 시작 시간
- 야간 종료 보호 종료 시간
- 종료 보호 프로그램 선택
- 종료 보호 프로그램 전체 해제
- YouTube 자동 실행 ON/OFF
- YouTube 감지 문구
- YouTube 쿨타임(분)
- 모든 설정 초기화
- 설정 저장

기본 설정:

방송 종료 자동 종료: ON
종료 대기 시간: 5분
야간 보호: 22:30 ~ 04:00
YouTube 자동 실행: OFF
YouTube 감지 문구: 똥! ㅋㅋ
YouTube 쿨타임: 60분

설정은 settings.ini에 저장됩니다.
보호 프로그램 목록은 protected_apps.ini에 저장됩니다.


5. 방송 세션 / 방송 시작시간 처리
----------------------------------

타임라인의 '방송시작'은 단순히 현재 날짜가 아니라 방송 세션의 시작시간을 기준으로 합니다.

방송이 자정을 넘어가더라도 같은 방송이 계속 진행 중이면
처음 방송을 시작한 날짜에 계속 귀속됩니다.

방송이 종료된 뒤 다시 시작하는 경우에는 다음 규칙을 사용합니다.

- OFF → ON 사이가 2시간 이내: 기존 방송 세션으로 처리
- OFF → ON 사이가 2시간 초과: 새로운 방송 세션으로 처리

따라서 짧은 방송 중단/재개 때문에 하나의 방송이 여러 날짜의 타임라인으로
잘못 분리되는 것을 방지합니다.


6. 타임라인
----------

타임라인 데이터는 다음 CSV 파일에 저장됩니다.

  timeline.csv

저장되는 기본 열:

  방송시작,방송시간,메모,기록시각,VOD링크

타임라인 메모는 Ctrl + Alt + K로 기록할 수 있습니다.

타임라인에는 방송 경과시간(시:분:초)과 메모가 저장되며,
기록 시각도 별도로 저장됩니다.


7. 타임라인 뷰어
----------------

Ctrl + Alt + O로 타임라인 뷰어를 열 수 있습니다.

주요 기능:

- 방송 시작 날짜를 기준으로 달력 표시
- 이전 달 / 다음 달 이동
- 오늘 날짜로 이동
- 선택한 날짜의 타임라인 목록 확인
- 타임라인 수정
- 타임라인 삭제
- VOD 재연결
- 타임라인 더블클릭으로 해당 VOD 열기
- 수동 타임라인 추가

자정을 넘어간 방송도 방송을 시작한 날짜에 귀속되므로,
날짜가 바뀌었다고 타임라인이 자동으로 다른 날짜로 분리되지 않습니다.


8. VOD 자동 연결
----------------

방송이 종료된 뒤 생성된 치지직 VOD를 타임라인과 자동으로 연결합니다.

자동 VOD 확인은 기본적으로 10분 간격으로 실행됩니다.

타임라인을 새로 저장했을 때도 VOD 연결을 즉시 한 번 시도하며,
아직 VOD가 존재하지 않는 경우 이후 자동 확인에서 다시 시도합니다.

중요:
- 이미 VOD 링크가 연결된 타임라인은 다시 검색하지 않습니다.
- 자동 재연결과 수동 'VOD 재연결' 모두 미연결 타임라인만 검사합니다.
- 현재 채널의 VOD를 검색합니다.
- 최대 20페이지 × 페이지당 30개, 최대 600개의 VOD를 검색합니다.
- 방송 시작시간과 VOD의 liveOpenDate는 기본적으로 ±180초의 허용 오차로 비교합니다.


9. 여러 VOD로 분할된 긴 방송 처리
---------------------------------

하나의 긴 방송이 여러 개의 VOD로 나뉘어 저장되는 경우를 고려하여
각 VOD의 duration을 이용해 전체 방송 경과시간과 VOD 내부 재생시간을 변환합니다.

예를 들어 하나의 방송이 VOD 2개로 나뉘었다면,
두 번째 VOD의 시작시간부터 다시 00:00:00으로 계산하는 것이 아니라
전체 방송에서의 경과시간을 기준으로 두 번째 VOD의 내부 재생 위치를 계산합니다.

따라서 타임라인을 클릭했을 때 가능한 경우 해당 시점의 VOD 내부 위치로 이동합니다.


10. 수동 타임라인
-----------------

타임라인 뷰어의 '+ 수동 타임라인' 버튼으로 직접 타임라인을 추가할 수 있습니다.

수동 타임라인에서는 치지직 VOD 링크를 입력하고,
VOD 정보를 이용해 방송 시작시간을 확인한 뒤
방송 경과시간과 설명을 저장할 수 있습니다.

수동으로 저장되는 VOD 링크 역시 가능한 경우 해당 타임라인 시점으로
바로 이동할 수 있도록 currentTime 값이 포함됩니다.

타임라인 수정은 기존 VOD 링크를 기준으로 진행하도록 되어 있으며,
삭제는 VOD 연결 여부와 관계없이 가능합니다.

삭제 전에는 확인창이 표시됩니다.


11. CSV 자동 백업
-----------------

타임라인 CSV를 변경하기 전에 자동 백업을 생성합니다.

백업 폴더:

  timeline_backup\

수동 추가 / 수정 / 삭제와 VOD 연결 변경 등에 따라 백업이 생성됩니다.

자동 처리 과정에서 같은 백업이 짧은 시간에 반복 생성되는 것을 방지하기 위해
자동 백업은 60초 단위 중복 방지 처리가 적용되어 있습니다.

백업 파일은 최대 100개까지 유지하며,
초과하는 오래된 백업은 자동으로 정리됩니다.


12. 업데이트
------------

트레이 메뉴의 '업데이트 확인'에서 GitHub Release의 최신 버전을 확인할 수 있습니다.

프로그램 시작 후에도 약 5초 뒤 자동으로 업데이트를 확인합니다.

업데이트 과정은 다음과 같습니다.

1) 현재 버전과 GitHub 최신 Release 버전 비교
2) 새 버전 확인
3) 업데이트 여부 확인
4) GitHub Release Asset 다운로드 시도
5) Asset 다운로드가 실패하면 해당 Release의 Raw 파일로 재시도
6) 다운로드한 AHK 파일의 AutoHotkey v2 요구사항 및 버전 확인
7) 업데이트 도우미 실행
8) 현재 프로그램 종료
9) 새 버전 파일 교체
10) 시작프로그램 바로가기 갱신
11) 새 버전 실행

프로그램의 현재 버전은 소스 내부의 CurrentVersion 값으로 관리합니다.
파일 이름과 CurrentVersion은 같은 버전으로 유지해야 합니다.


13. 시작프로그램
----------------

프로그램 폴더에 AutoHotkey64.exe가 있으면 업데이트 과정에서
Windows 시작프로그램 바로가기를 자동으로 갱신하도록 되어 있습니다.

기본 바로가기 이름:

  독케익시청자용.lnk

기존의

  독케익시청자용v*.lnk

형식의 오래된 바로가기도 정리하도록 되어 있습니다.

시작프로그램 바로가기는 현재 업데이트된 AHK 파일을
같은 폴더의 AutoHotkey64.exe로 실행하도록 구성됩니다.


14. 프로그램 폴더의 주요 파일
------------------------------

필수/주요 파일:

  dogcake_proviewer_v1.8.34.ahk
  AutoHotkey64.exe
  dogicon.ico                 (트레이/바로가기 아이콘으로 사용 가능)

실행 중 자동으로 생성/사용되는 파일:

  settings.ini
  protected_apps.ini
  timeline.csv
  timeline_backup\
  chzzk_chat_queue.txt
  chzzk_chat_trigger.txt

채팅 감지 기능 관련:

  chzzk_chat.ps1


15. 설치 / 실행
---------------

1. 프로그램 파일과 AutoHotkey64.exe를 같은 폴더에 둡니다.
2. dogcake_proviewer_v1.8.34.ahk를 AutoHotkey v2로 실행합니다.
3. 필요한 경우 Ctrl + Alt + L에서 설정을 저장합니다.
4. Ctrl + Alt + O에서 타임라인 뷰어를 사용할 수 있습니다.

AutoHotkey v2 환경이 필요합니다.


16. 주의사항
------------

- 치지직 API 또는 네트워크 상태에 따라 방송 상태/VOD 확인이 실패할 수 있습니다.
- 프로그램이 종료된 상태에서는 방송 감시 및 자동 종료 처리가 동작하지 않습니다.
- Windows 종료 예약은 프로그램의 설정과 야간 보호/보호 프로그램 조건에 따라 취소될 수 있습니다.
- 타임라인 CSV를 직접 수정할 경우 CSV 형식이 깨지지 않도록 주의해야 합니다.
- VOD가 아직 생성되지 않았거나 치지직 VOD 정보와 방송 시작시간을 매칭할 수 없는 경우 자동 연결이 늦어질 수 있습니다.
- 이미 VOD가 연결된 타임라인은 자동 VOD 검색 대상에서 제외됩니다.


17. 데이터 파일 요약
---------------------

settings.ini
- 방송 종료 자동 종료 여부
- 종료 대기 시간
- 야간 보호 시간
- YouTube 자동 실행 설정
등의 프로그램 설정을 저장합니다.

protected_apps.ini
- 종료 보호 대상으로 지정한 실행 파일 목록을 저장합니다.

timeline.csv
- 방송 타임라인의 실제 데이터입니다.

 timeline_backup\
- timeline.csv 변경 전 생성되는 백업 파일을 보관합니다.

chzzk_chat_queue.txt
- 채팅 감지 결과를 프로그램이 전달받는 데 사용하는 파일입니다.

chzzk_chat_trigger.txt
- 현재 설정된 YouTube 감지 문구 전달에 사용됩니다.


18. 버전 관리
-------------

버전은 일반적으로 다음 형식을 사용합니다.

  X.Y.Z

프로젝트에서의 버전 관리 기준은 다음과 같이 사용하는 것을 권장합니다.

- X: 이전 버전과 호환되지 않는 큰 변경
- Y: 기능 추가/변경
- Z: 버그 수정 및 작은 개선

현재 프로그램 버전은 v1.8.34입니다.
